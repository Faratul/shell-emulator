# Эмулятор командной строки ОС (Вариант №16)

GUI-эмулятор языка оболочки UNIX-подобной ОС. Проект выполняется поэтапно,
каждый этап фиксируется отдельным коммитом.

> **Текущий этап: Этап 2 — Конфигурация.**
> Добавлены параметры командной строки, стартовый скрипт и отладочный вывод
> параметров. Реальная VFS и логика команд — на следующих этапах.

## 1. Общее описание

Приложение имитирует работу командной строки UNIX-подобной ОС в виде
графического интерфейса (GUI), написанного на Python с использованием
`tkinter`. Пользователь вводит команды в поле ввода, результат выполнения
выводится в область истории диалога — как в обычном терминале.

Заголовок окна отображает имя VFS: имя файла/папки из параметра `--vfs`,
а если параметр не задан — `vfs`.

Команды `ls` и `cd` являются заглушками: они печатают своё имя и
переданные аргументы.

## 2. Описание всех функций и настроек

### Команды

| Команда          | Поведение                                   |
| ---------------- | ------------------------------------------- |
| `ls [аргументы]` | заглушка: выводит `ls` и аргументы          |
| `cd [аргументы]` | заглушка: выводит `cd` и аргументы          |
| `echo [текст]`   | выводит переданный текст                    |
| `exit`           | завершает работу эмулятора                  |

Неизвестная команда — сообщение `Command "..." not found`, приложение не
закрывается.

### Параметры командной строки (Этап 2)

| Параметр        | Описание                                  |
| --------------- | ----------------------------------------- |
| `--vfs PATH`    | путь к физическому расположению VFS       |
| `--script PATH` | путь к стартовому скрипту                 |

При запуске все заданные параметры выводятся отладочными строками
`[debug] ...` — в окно эмулятора и в stdout. Если путь не существует,
рядом выводится `НЕ НАЙДЕН` (запуск при этом не прерывается).

### Стартовый скрипт

- Текстовый файл, по одной команде эмулятора в строке (пример: `src/start`).
- Комментарии начинаются с `#` (строка целиком или хвост строки); пустые
  строки пропускаются.
- При выполнении на экране отображаются и ввод (с приглашением), и вывод —
  с небольшой паузой между командами, как живой диалог.
- Ошибочная команда выводит сообщение, скрипт продолжает работу.
- Если скрипт не найден — сообщение об ошибке, эмулятор остаётся в
  интерактивном режиме.

## 3. Сборка и запуск

Требования: Python 3.9+ (только стандартная библиотека, включая `tkinter`).

```bash
./run.sh                                          # без параметров
./run.sh --vfs src/vfs --script src/start         # с параметрами
```

Тесты:

```bash
python3 -m unittest discover -s tests -v          # unit-тесты
```

Скрипты ОС для проверки параметров командной строки (папка `tests/`):

```bash
tests/test_no_params.sh        # без параметров (окно закрыть вручную)
tests/test_vfs.sh              # только --vfs
tests/test_vfs_missing.sh      # --vfs с несуществующим путём
tests/test_script.sh           # только --script
tests/test_all_params.sh       # оба параметра
tests/test_script_missing.sh   # несуществующий скрипт
```
