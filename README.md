# Эмулятор командной строки ОС (Вариант №16)

GUI-эмулятор языка оболочки UNIX-подобной ОС. Проект выполняется поэтапно,
каждый этап фиксируется отдельным коммитом.

> **Текущий этап: Этап 1 — REPL.**
> Реализован минимальный прототип: графический интерфейс с диалогом
> ввода-вывода, парсер аргументов и команды-заглушки. Подключение реальной
> VFS, конфигурации через параметры командной строки и остальных команд
> запланировано на следующих этапах.

## 1. Общее описание

Приложение имитирует работу командной строки UNIX-подобной ОС в виде
графического интерфейса (GUI), написанного на Python с использованием
`tkinter`. Пользователь вводит команды в поле ввода, результат выполнения
выводится в область истории диалога — как в обычном терминале.

Заголовок окна отображает имя VFS. Поскольку подключение файловой системы
запланировано на Этапе 3, на данном этапе используется заглушечное имя VFS
(константа в коде), которое в дальнейшем будет браться из параметров запуска.

На этом этапе команды `ls` и `cd` являются заглушками: они не выполняют
реальных файловых операций, а лишь показывают, что были корректно распознаны
парсером — печатают своё имя и переданные им аргументы.

## 2. Описание всех функций и настроек

### Парсер команд

- Разбивает введённую строку на имя команды и список аргументов.
- Корректно обрабатывает аргументы, заключённые в кавычки (`"..."`), — такой
  аргумент передаётся командам как единый элемент, даже если внутри есть
  пробелы.
- Сообщает об ошибке разбора, если кавычка не закрыта.

### Команды

| Команда | Статус на Этапе 1 | Поведение |
|---|---|---|
| `ls [аргументы]` | заглушка | выводит `ls` и список полученных аргументов |
| `cd [аргументы]` | заглушка | выводит `cd` и список полученных аргументов |
| `exit` | реализована | завершает работу эмулятора |

### Обработка ошибок

- Неизвестная команда — выводится сообщение об ошибке, приложение не
  закрывается.
- Некорректный синтаксис (например, незакрытая кавычка) — выводится
  сообщение об ошибке разбора.

### Настройки

На Этапе 1 параметры конфигурации отсутствуют — имя VFS для заголовка окна
задаётся константой в исходном коде. Поддержка параметров командной строки
(путь к VFS, путь к стартовому скрипту) появится на Этапе 2.

## 3. Сборка и запуск

Требования: Python 3.9+ (используется только стандартная библиотека,
включая `tkinter`, — дополнительных зависимостей нет).

Запуск приложения:

```bash
python src/main.py
```

или через скрипт запуска:

```bash
./run.sh        # Linux/macOS
run.bat         # Windows
```

Запуск тестов:

```bash
python -m pytest tests/
```

## 4. Примеры использования

После запуска в окне эмулятора можно ввести, например:

```
ls -l "My Documents"
ls ['-l', 'My Documents']

cd ..
cd ['..']

foobar
Ошибка: неизвестная команда 'foobar'

ls "unterminated
Ошибка: незакрытая кавычка в аргументе

exit
```
